### 🎨 UI Style (Tetap Konsisten)

#### Card Design:
```tsx
<Link className="bg-white rounded-lg overflow-hidden shadow-sm border border-gray-200 hover:shadow-lg transition-shadow">
  {/* Image dengan badge */}
  <div className="relative h-48">
    <img src={campaign.image} />
    {urgent && <div className="bg-red-600">URGENT</div>}
    {badge && <div className="bg-gradient-to-t from-black/70">{badge}</div>}
  </div>
  
  {/* Content */}
  <div className="p-4">
    <h3>{title}</h3>
    <p>{description}</p>
    
    {/* Organizer dengan verified badge */}
    <div className="flex items-center gap-2">
      <Check className="text-white bg-green-600" />
      <span>{organizer}</span>
      {verified && <Check className="text-blue-600" />}
    </div>
    
    {/* Progress bar */}
    <div className="bg-gray-200 rounded-full h-2">
      <div className="bg-green-600 h-2 rounded-full" style={{width: `${progress}%`}} />
    </div>
    
    {/* Stats */}
    <div className="flex justify-between">
      <div>
        <span>Terkumpul</span>
        <p className="font-bold">{formatCurrency(raised)}</p>
      </div>
      <div>
        <span>Sisa Hari</span>
        <p className="font-bold">{daysLeft}</p>
      </div>
    </div>
  </div>
</Link>
```

#### Color Scheme:
- **URGENT Badge**: `bg-red-600` - Merah untuk prioritas tinggi
- **Progress Bar**: `bg-green-600` - Hijau untuk progress
- **Verified Check**: `bg-green-600` + `text-blue-600` - Trust indicators
- **Hover Effect**: `hover:shadow-lg` - Subtle interaction
